# 🎮 Administração em Jogo

**Aprender Administração pode ser divertido!**

O Administração em Jogo é uma aplicação web educativa desenvolvida para tornar o aprendizado de conceitos da área de Administração mais interativo e dinâmico. Por meio de uma roleta de assuntos, histórias explicativas e um quiz com tempo limitado, os participantes podem testar seus conhecimentos e competir por uma posição no ranking.

## 📌 Sobre o projeto

O projeto foi desenvolvido com o objetivo de unir educação e gamificação, transformando conteúdos administrativos em uma experiência de aprendizagem mais envolvente.

O participante acessa o sistema, realiza seu cadastro, gira a roleta para descobrir o assunto da rodada, acompanha uma breve explicação educativa e responde às perguntas do quiz para acumular pontos.

## ✨ Funcionalidades

- 📝 **Cadastro de participantes:** identificação do jogador por nome e turma.
- 🎡 **Roleta de assuntos:** seleção do tema da rodada.
- 📚 **Histórias educativas:** explicações curtas sobre os assuntos de Administração.
- ❓ **Quiz interativo:** perguntas de múltipla escolha para testar os conhecimentos.
- ⏱️ **Contagem regressiva:** tempo limitado para responder às perguntas.
- 📊 **Pontuação automática:** atribuição de pontos conforme os acertos.
- 🏆 **Ranking Top 10:** classificação dos participantes com melhores resultados.
- 📱 **Acesso por QR Code:** facilidade de acesso ao jogo por meio do endereço publicado.

## 📚 Assuntos abordados

O jogo trabalha com quatro áreas de conhecimento:

1. **Operações e Logística:** estoque, entregas, planejamento de rotas e eficiência operacional.
2. **Empreendedorismo:** oportunidades, plano de negócios, público-alvo e custos.
3. **Recursos Humanos:** recrutamento, treinamento, comunicação e clima organizacional.
4. **Finanças e Contabilidade:** receitas, despesas, fluxo de caixa e resultados financeiros.

## 🛠️ Tecnologias utilizadas

- **PHP:** processamento das informações e regras do jogo.
- **HTML5:** estrutura das páginas.
- **CSS3:** estilos e apresentação visual.
- **JavaScript:** contagem regressiva, barra de tempo e interatividade.
- **Sessões PHP:** controle do participante e do andamento da rodada.
- **Banco de dados:** armazenamento das informações, conforme a configuração do projeto.
- **XAMPP:** ambiente local de desenvolvimento e testes.
- **Git e GitHub:** versionamento e gerenciamento do código-fonte.

## 🚀 Como executar o projeto localmente

### Pré-requisitos

- XAMPP instalado.
- PHP compatível com o projeto.
- Navegador atualizado.
- Banco de dados configurado, caso seja exigido pelos módulos utilizados.

### Instalação

**1. Clone o repositório**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço real do seu repositório no GitHub.

**2. Coloque o projeto no diretório do XAMPP**

Copie ou clone a pasta do projeto para:

```text
C:\xampp\htdocs\
```

**3. Inicie o ambiente**

Abra o painel de controle do XAMPP e inicie os serviços necessários ao projeto.

**4. Configure o banco de dados**

Se o sistema utilizar banco de dados, configure as credenciais e os parâmetros de conexão no arquivo correspondente, como `conexao.php`. Importe a estrutura do banco, se houver um arquivo SQL disponível.

**5. Acesse a aplicação**

Abra o navegador e acesse:

```text
http://localhost/NOME_DA_PASTA/
```

Substitua `NOME_DA_PASTA` pelo nome real do diretório do projeto.
