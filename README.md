# adiministracao-em-jogo

## PASSO A PASSO
* 1. Acesso pelo QR Code
- QR Code direciona para o sistema.
- Pergunta se pode comecar o jodo (sim)
- Cadastro do participante.
- Roleta de assuntos
- Breve historia do assunto selecionado em quadrinhos
- Quiz
- Tela de pontuacao informado o desempenho no quiz
- Ranking top 10,
- Fim do jogo:

* 2. Cadastro rápido
Precisamos coletar apenas o necessário, por exemplo:
- Nome
- Turma/curso
O sistema gera um identificador para a participação.

* 3. Roleta
A roleta terá 4 assuntos administrativos.
Por exemplo:
             ┌──────────────┐
             │  Marketing   │
             └──────┬───────┘
                    │
       ┌────────────┼────────────┐
       │             ▼            │
 Gestão          🎯 ROLETA      Finanças
       │                          │
       └────────────┬────────────┘
                    │
             Recursos Humanos


* 4. História em quadrinhos
Depois que a roleta escolher um assunto:
ASSUNTO: RECURSOS HUMANOS

[Quadrinho 1]
Personagem apresenta uma situação.

[Quadrinho 2]
Surge um problema administrativo.

[Quadrinho 3]
Outro personagem explica o conceito.

[Quadrinho 4]
Conclusão.

Depois:
"Você está preparado? Começar Quiz"

* 5. Quiz
Cada assunto terá perguntas cadastradas.
Exemplo:
Qual é uma das principais funções da Administração?

O aluno terá 5 segundos.

Quando responder:
- resposta correta → soma pontos
- resposta errada → 0 pontos
- tempo esgotado → 0 pontos
Depois passa automaticamente para a próxima.

* 6. Pontuação
Situação	Pontos
Acertou muito rápido	100
Acertou	80
Errou	0
Tempo esgotado	0

quanto mais rápido responder, maior a pontuação.
Por exemplo:
5 segundos restantes → 100 pontos
4 segundos → 90 pontos
3 segundos → 80 pontos
2 segundos → 70 pontos
1 segundo → 60 pontos
0 → 0
